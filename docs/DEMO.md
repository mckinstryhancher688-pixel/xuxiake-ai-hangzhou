# 演示与验收手册 · 带爸妈出游

主线：**说一句爸妈的情况 → 系统追问全程能走多久 → 生成真实路线 → 嫌远就把分钟调小 → 站变少，没花钱。**

适用范围为带长辈的杭州半日出游。本文只组织演示与复现，不改变部署方式、密钥配置或求解逻辑。
能力是否已经真实验证，以 [EVIDENCE.md](EVIDENCE.md) 为准；投稿正文见 [SUBMISSION.md](SUBMISSION.md)，
上线架构与安全事项仍分别由 [DEPLOYMENT.md](DEPLOYMENT.md)、[SECURITY.md](SECURITY.md) 说明。

> 旧版本的「旅行搭子双人协商」演示已经停用（双人协商代码保留但冻结），本手册不再包含它。

## 1. 先选一条有证据的故事

2026-11-18 的真机验收（[证据](../evidence/family-real-accept.json)）：首页选「1 小时」，核验出「文创街区」的真实路线
西湖天地 → 南宋御街 → 馒头山社区居委会（步行 81 分钟）。

| 条件 | 结果 | 新增高德调用 |
| --- | --- | --- |
| 全程 1 小时 | 2 站，步行 43 分钟 | 0 |
| 全程 30 分钟 | 排不出，写明「放宽到 43 分钟可以排 2 站」 | 0 |
| 全程 1.5 小时 | 3 站，合计 191 分钟（81 + 3 × 30 + 20） | 0 |
| 1.5 小时 + 每站停 60 分钟 | 2 站，说明是停留把第 3 站压掉了 | 0 |

现场重新生成时，按**当次实际路线**讲，不要求出现同一组站点或分钟数。
不要预设「30 分钟一定排不出」；只有实测数据支持时才展示「排不出」。

## 2. 两分钟演示（建议时长，非官方规格）

| 时间 | 操作与画面 | 台词要点 |
| --- | --- | --- |
| 0:00–0:15 | 首页，只有一个问题 | “带爸妈出门，最怕的是走不动。我们只问一件事：爸妈全程一共能走多久。” |
| 0:15–0:40 | 在输入框里输入「我妈膝盖不好」，点「读一下」 | “它没有替我猜一个数，而是追问全程大概能走多久。模型不出数字。” |
| 0:40–0:50 | 再输入「走半小时就得歇」 | “这说的是一口气，不是全程，它也分得清，还是追问。” |
| 0:50–1:05 | 点「1 小时」，点「生成我的路线」（冷核验可剪辑，标注等待） | “飞猪给候选地点，高德逐段实测每一段要走多久。” |
| 1:05–1:25 | 路线与高德真实底图；账单一行 | “合计 = 步行（高德实测）+ 停留几站乘几分钟 + 缓冲 20 分钟，四小时以内。” |
| 1:25–1:45 | 「调整」页把分钟调小，站变少；看「新增高德调用：0 次」 | “嫌远就把分钟调小。改条件不再花钱，屏幕上写着 0 次。” |
| 1:45–2:00 | 「给爸妈看」大字版 | “最后把手机递给爸妈：去哪几个地方、走多久、厕所在哪。” |

读一句话的镜头每次都是一次真实百炼调用（`qwen-flash`），录制时一句一次，不要反复重试凑效果。
冷核验、等待模型的过程可以压缩，但要标注等待或剪辑，不能拼成虚构的连续操作。

## 3. 演示前准备

- 本地启动说明见 [README](../README.md#快速开始)。项目要求 Node ≥20.9.0；验收使用 Node 24.20.0。
- 启动命令：`npm run build`，然后 `npm run start -- -H 127.0.0.1 -p 3000`。
- **只用 `http://127.0.0.1:3000` 打开。** 高德 JS key 白名单里是 `127.0.0.1`，用 `localhost` 会报 `INVALID_USER_DOMAIN`，地图退回手绘示意。
- 核对自己的 8 项服务配置，但不要展示值。只读状态端点能看额度与配置形状，**不能证明所有凭据可用**。
- 完成构建、启动最终服务实例之后再预热。事实层存在内存里，**不要在录制期间重启服务**，否则要重新核验（花钱）。
- 默认单选「文创街区」，假定杭州时间 13:00 出发。「自然风光」可能返回千岛湖这类远郊候选，演示不要用它。
- 公网入口 [travel.peiqirui.com](http://travel.peiqirui.com/) 目前仍是旧版本 `c906649`；新版本部署前不要用公网录新流程。
- 手机演示：手机不能访问电脑的 `127.0.0.1`。要用真机，必须先部署到线上域名（并把域名加进高德白名单）。
- 只录产品页面，折叠调试面板，不录配置文件、原始响应、终端密钥或本机个人路径。

### 调用成本口径

| 动作 | 当前规则 / 2026-11-18 实测 |
| --- | --- |
| 首次冷核验（文创街区单类别） | 实测高德 37 次（POI 12 + 步行 25）、飞猪 1 次；实际数随候选、缓存和失败重试变化 |
| 读一句话 | 每句 1 次百炼 `qwen-flash`；60 次/小时上限 |
| 「我到了」讲解 | 每次 1 个百炼托管智能体回合；40 回合/小时上限 |
| 改全程分钟数、改每站停留 | 在已实测路段上本地重算，**0 新增高德调用** |
| 把没测过的站加进来 | 需要补测；单人流程不自动补测，只如实说明 |

已过期的事实（超过 6 小时或服务重启）不能续期，要重新核验。

## 4. 手工操作与观感清单

电脑端：

- [ ] 首页只有「爸妈全程一共能走多久」一个问题；刚打开时没有选项被预先选中。
- [ ] 输入「我妈膝盖不好」：标题换成追问，并标注「按您说的情况追问」；选项没有被替你选上。
- [ ] 输入「全程最多走一个小时」：自动选上 1 小时，并复述原话。
- [ ] 输入「走半小时就得歇」：**不会**选上 30 分钟，提示这像是一口气走多久。
- [ ] 顶部在没有路线时不显示演示行程的数字。
- [ ] 生成后地图是高德真实底图（左上角写「高德 JS API 2.0 真实地图」），不是手绘示意。
- [ ] 账单写「停留 N 站 × M 分钟」和「缓冲 20 分钟（固定）」。
- [ ] 「调整」页只有两组按钮：全程能走多久、每站停留；没有「一口气最多走多远」，也没有「少走一点」。
- [ ] 每次改条件都显示「本次重解新增高德调用：0 次」。
- [ ] 排不出时说清是哪条条件、放宽到多少能排出；没有悄悄退回超限路线。
- [ ] 百炼失败显示真实错误；不以固定话术冒充模型。

手机视口（390×844）：

- [ ] 首屏能看到问题、输入框和「生成我的路线」，没有横向滚动。
- [ ] 调整页 8 个按钮都在屏内。
- [ ] 大字版放到最大字号，「字小 / 字大 / 退出」仍各是一行字。
- [ ] 若只用浏览器手机视口，记录为「手机视口」，不写「真机」。

## 5. 验证命令：按目的选，不一次全跑

### 零付费

```bash
npm run test:offline          # 459 项离线检查/场景，16 个套件，不需要启动服务
```

以下需要先 build 并以 `-H 127.0.0.1` 启动服务，全部用桩，零真实调用：

```bash
node evidence/preflight-ui.mjs                                         # 步行时间上限、每站停留、大字版，50 项
node --import ./evidence/register-alias.mjs evidence/understand-ui.mjs # 读一句话界面，26 项
node evidence/toilet-ui.mjs                                            # 无障碍洗手间，14 项
node evidence/source-evidence-browser-probe.mjs                        # 来源证据，14 项
node --import ./evidence/register-alias.mjs evidence/amap-js-diagnose.mjs # 高德底图加载（只加载 SDK）
```

### 真实付费（跑之前先报预算并获批）

```bash
CONFIRM_PAID=yes node evidence/family-real-accept.mjs    # 真机端到端：一次核验约 27–37 次高德 + 1 次飞猪，之后 0
CONFIRM_PAID=yes node evidence/understand-real-probe.mjs # 读一句话 40 句：40 次百炼
```

PowerShell 设置环境变量的写法：`$env:CONFIRM_PAID = 'yes'`；非默认地址用 `$env:BASE_URL = 'http://127.0.0.1:端口'`。
不要为确认文案反复运行真实脚本。`phase6-*`、`phase8-accept`、`phase9-accept`、`plan-api-smoke` 是旧界面与双人协商的历史脚本，
其中不少选择器已经对不上当前界面，不作为当前版本的验收依据。
