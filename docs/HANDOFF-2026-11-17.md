## 3. 现在的产品流程

1. **首页一问**：「爸妈全程一共能走多久？」选项是 30 分钟 / 1 小时 / 1.5 小时 / 不确定（不设上限）。
2. **也可以直接说一句话**，比如「我妈膝盖不好」。百炼读这句话（`/api/understand`）：
   - 话里有确定的全程时长 → 代码从原话里算出分钟数，自动选上并复述原话；
   - 只说身体情况、或者说的是「一口气走多久」、或者时长含糊 → 换成追问，让用户点选项；
   - 没读成 → 如实写原因，退回默认问题。
3. **生成我的路线**：飞猪拿候选，高德逐段实测，按上面的分钟数排出路线。
4. **调整页**：改分钟数、改每站停留时长，都在已实测路段上重算，**不再花钱**。
5. **给爸妈看**：大字版，只讲去哪几个地方、走多久、厕所在哪。

## 6. 已知的坑

| 坑 | 说明 |
|---|---|
| **只能用 `127.0.0.1` 打开** | 高德 JS key 的白名单里是 `127.0.0.1`。用 `localhost` 打开会报 `INVALID_USER_DOMAIN`（infocode 10006），地图退回手绘示意图 |
| 白名单不认端口 | 控制台里写 `localhost:3000` 会报「有不符合规范的域名」 |
| 改 `.env.local` 要重启服务 | Next 只在启动时读环境变量 |
| 重启时旧进程可能还占着 3000 | 先 `Get-NetTCPConnection -LocalPort 3000 -State Listen` 看是谁，确认是 `next start` 再结束它 |
| 事实层是内存态 | 重启即丢；真机验收必须在同一个服务进程里连着跑完 |
| 「自然风光」类别不稳定 | 飞猪会返回千岛湖、径山这种几十公里外的点。演示和验收用「文创街区」 |
| 高德没有路面无障碍数据 | 永远不要说「轮椅可通行」「无台阶」 |
| PowerShell 里中文会乱码 | 先 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`，或者把输出重定向到文件再读 |
| 管道会吞退出码 | `npm run build | Select-Object -Last 5` 显示成功不代表成功，要看 `$LASTEXITCODE` |
